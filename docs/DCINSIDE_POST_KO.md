# 디시인사이드 게시글용 소개문

## 제목 예시

Codex에서 웹 GPT를 계획·검토·수정·멀티 에이전트로 굴리는 자동화 공개함

## 본문

Codex 작업하다 보면 웹 ChatGPT를 같이 쓰고 싶을 때가 있는데, 직접 브라우저 매크로를 붙이면 은근히 문제가 많았음.

- 질문 전송 여부가 애매한데 중복으로 또 보냄
- 다른 프로젝트 탭을 현재 작업으로 착각함
- 앱 등록 확인하다가 실행 중인 대화 탭을 건드림
- 완료 탭은 계속 쌓이고 진행 중인 탭은 잘못 닫힘
- 계획, 검토, 수정 프롬프트가 전부 반례 찾기 위주로 좁아짐
- Pro와 일반 GPT의 앱 사용 규칙이 섞임

그래서 공개 `agbrowse`를 브라우저 엔진으로 그대로 쓰고, 그 위에 Codex용 실행·복구·앱 연결 계층만 얇게 붙인 프로젝트를 공개함.

저장소:

https://github.com/ventianima-lab/codexpro-automation

지원하는 모드는 대략 이럼.

- 일반 GPT: 질문에 직접 답변
- 계획 모드: 여러 방법을 비교해서 실행 계획 작성
- 검토 모드: 기존 계획이나 코드의 실제 결함 검증
- 수정 모드: CodexPro 앱으로 작업공간을 보고 직접 수정·테스트
- 지휘 모드: 웹 GPT가 탐색·수정·테스트를 주도해서 로컬 Codex 토큰 사용 최소화
- GPT 종합모드: 필요하면 심층 리서치 → 계획 → 멀티 GPT → 검토 → 구현 → 로컬 검증
- 웹 멀티 GPT: 여러 독립 ChatGPT 대화를 실제 병렬 실행해서 제안·정제·병합·판정
- 심층 리서치: 최신 외부 자료와 출처 조사
- Pro: 앱 없이 첨부 파일만 쓰는 넓은 고난도 판단 모드

중요한 규칙은 Pro만 앱 금지이고, 나머지는 전부 정확한 CodexPro 앱 연결이 필수라는 점임. 수정 모드에서 앱 없이 첨부만 보고 수정한 척하는 식의 경로는 막아 둠.

같은 프로젝트에서는 질문 하나만 돌고, 프로젝트가 다르면 서로 다른 브라우저 세션과 탭으로 병렬 실행 가능함. 브라우저가 꺼져도 기록된 실행 ID와 대화 URL로 원래 작업을 먼저 찾고, 보냈는지 애매한 상태에서 새 질문을 중복 전송하지 않음.

탭도 무조건 닫거나 무조건 남기는 방식이 아님.

- 결과 저장과 완료가 확인된 정확한 작업 탭은 자동 종료
- 응답 중, 전송 불확실, 수동 탭, 다른 프로젝트 탭은 보호
- 앱 등록·삭제·권한 설정은 새 유틸리티 탭에서만 처리

필요한 건 Windows, PowerShell, Python 3, Node.js 20 이상, Chrome/Chromium, Codex 앱, ChatGPT 로그인임. **커스텀 앱을 쓰므로 ChatGPT 설정 → 앱 → 고급 설정에서 개발자 모드도 켜야 함.** 계정이나 워크스페이스에 개발자 모드/앱 만들기 메뉴가 없으면 관리자 권한 또는 지원 계정이 필요하고, 실행기가 그 상태를 안내한 뒤 질문 전송을 막음. Pro는 앱을 안 쓰는 첨부 전용이라 이 사전조건에서 제외됨.

`agbrowse`와 `codexpro`는 저장소 안에 복사하지 않고 외부 패키지로 사용함. 기본 터널은 Cloudflare 동적 주소고, 고정 ngrok은 따로 설정한 사람만 선택해서 쓸 수 있음.

설치는 저장소 받은 다음 PowerShell에서:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -WhatIf
powershell -ExecutionPolicy Bypass -File .\install.ps1
powershell -ExecutionPolicy Bypass -File .\doctor.ps1
```

설치 전에 `-WhatIf`로 어떤 파일이 들어가는지 볼 수 있고, 기존 파일은 백업과 해시 영수증을 남김. 삭제·롤백 스크립트도 있음.

아직 ChatGPT 웹 UI와 외부 패키지에 의존하는 자동화라 업데이트에 따라 고칠 부분은 생길 수 있음. 대신 브라우저 엔진을 직접 포크하지 않고 공개 원본을 유지해서 자동화 경로 자체의 유지보수 부담을 줄이는 방향으로 만들었음.
