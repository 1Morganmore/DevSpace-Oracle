이 문서는 예전 CodexPro/agbrowse 기반 소개문을 더 이상 배포하지 않도록
남겨 둔 호환 파일입니다.

현재 구조는 새 GPT 작업을 전부 Oracle로 실행합니다. 일반 GPT·종합모드·
웹 멀티 GPT는 DevSpace를 사용하고, Pro는 앱 없이 첨부 전용으로
실행합니다. CodexPro와 agbrowse는 과거 실행 복구에만 남아 있으며 새
작업의 대체 경로로 사용하지 않습니다.
